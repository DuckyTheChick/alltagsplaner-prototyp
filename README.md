# 🌸 Alltagsplaner – Mein Webentwicklungsprojekt

**Ein persönliches Lern- und Entwicklungsprojekt zur Erstellung einer erweiterbaren Alltagsplaner-Webanwendung.**

> **Projektstatus:** In Entwicklung  
> **Aktuelle Phase:** HTML-Grundlagen und erster Prototyp  
> **Technologien:** HTML · CSS · JavaScript (schrittweiser Aufbau)

---

## 💗 Meine Projektidee

Ich möchte eine Webanwendung entwickeln, die dabei hilft, den Alltag übersichtlich, flexibel und individuell zu organisieren.

Dabei geht es nicht nur um eine gewöhnliche Aufgabenliste. Langfristig soll ein vielseitiger Alltagsplaner entstehen, der unterschiedliche Planungsfunktionen und individuell nutzbare Widgets miteinander verbindet.

Die Entwicklung erfolgt schrittweise: von der Konzeption über das Erlernen der benötigten Technologien bis zur fertigen Webanwendung.

## ✨ Geplante Funktionen

Unter anderem sind folgende Möglichkeiten vorgesehen:

- Aufgaben erstellen, bearbeiten und abschließen
- Aufgaben nach Priorität und Dringlichkeit organisieren
- Tages- und Wochenplanung
- Flexible Anpassung der Planung
- Unterschiedliche Planungsansichten
- Individuell nutzbare Widgets

Der vollständige geplante Funktionsumfang ist in der Funktionssammlung dokumentiert.
